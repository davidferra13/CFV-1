# Decision log

What was preserved, what was consolidated, what was replaced, what was newly decided, and why. Every future addition to the design system appends here.

Evidence precedence used throughout: (1) explicit repository instructions, (2) approved documented design decisions, (3) repeated production patterns, (4) strong existing components, (5) isolated or experimental implementations, (6) new decisions to fill genuine gaps.

## Replaced or fixed (defects, not preferences)

| #    | Change                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | Why                                                                                          | Rollback                                                                                                                                                              |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R-01 | **Layer scale is now real.** `z-dialog`, `z-float`, `z-chrome` and `z-toast` were used in 122 files while being undefined in `tailwind.config.ts`, so every dialog and popover stacked by DOM order and `DropdownMenuContent`'s explicit `z-50` painted over modals. Defined the full scale and moved that dropdown to `z-float` (70), deliberately above `z-dialog` (60) so a menu opened inside a modal renders over it.                                                                                                                                                                                                       | Broken stacking is a functional bug.                                                         | Remove the `zIndex` block from the generated tailwind section.                                                                                                        |
| R-02 | **`prefers-reduced-motion` is now global.** `docs/ui-ux-full-reconciliation.md` Q7 recorded this as "RESOLVED. One CSS block fixes everything." The block was never written; only 10 scoped blocks covering the discovery rail existed against roughly 660 `animate-*` usages. Implemented, with two corrections to the documented version: entrance animations are forced to their final state (`animation-fill-mode: forwards`, `opacity: 1`, `transform: none`) so nothing is left invisible, and loading spinners, skeleton shimmer and progress fills are exempt because they are the only feedback that work is happening. | WCAG 2.1 SC 2.3.3. The decision existed; the code did not.                                   | Delete the reduced-motion block from `tokens.json` generation.                                                                                                        |
| R-03 | **`font-display` now resolves to Playfair.** It previously pointed at the same system stack as `font-sans`, making the utility a no-op across 124 headings, while `.font-display-serif` carried the brand voice on a handful of others. The documented intent is unambiguous: the display family is the brand's editorial voice on headings. **This is the highest-visual-impact change in this pass.**                                                                                                                                                                                                                          | Tier-2 evidence. Two utilities meaning the same thing is not a decision, it is a regression. | One line in `tailwind.config.ts`: replace the `display` array with the `ui` array directly above it. `font-ui` was added as the explicit alias for the old behaviour. |
| R-04 | **`ease-spring` and `ease-bounce` are now real utilities.** `ease-spring` was used 34 times while undefined.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Same class of bug as R-01.                                                                   | Remove `transitionTimingFunction` from the generated block.                                                                                                           |
| R-05 | **`Switch` applies `disabled`.** It was spread onto the visually-hidden `<input>` while the interactive element is the `<button>`, so `disabled:opacity-50` could never match and a disabled Switch still toggled.                                                                                                                                                                                                                                                                                                                                                                                                               | Functional bug.                                                                              | `components/ui/switch.tsx`                                                                                                                                            |
| R-06 | **`Button` with `href` respects `disabled` and `loading`.** An anchor has no `disabled` attribute, so it now drops its `href`, leaves the tab order, sets `aria-disabled` and disables pointer events. Previously a loading link showed a spinner and stayed fully clickable.                                                                                                                                                                                                                                                                                                                                                    | Functional bug.                                                                              | `components/ui/button.tsx`                                                                                                                                            |
| R-07 | **`Alert` announces.** ~135 call sites rendered a plain `<div>` that no screen reader announced. error and warning are `role="alert"` assertive; info and success are `role="status"` polite; callers can override `role` for static page furniture.                                                                                                                                                                                                                                                                                                                                                                             | Accessibility defect.                                                                        | `components/ui/alert.tsx`                                                                                                                                             |
| R-08 | **Interactive `Card` is keyboard operable.** With an `onClick` it now takes `role="button"`, `tabIndex 0`, Enter/Space activation and a visible focus ring. It was a `cursor-pointer` div with no focus ring and no keyboard path.                                                                                                                                                                                                                                                                                                                                                                                               | Accessibility defect.                                                                        | `components/ui/card.tsx`                                                                                                                                              |
| R-09 | **Button focus-ring offset follows the theme.** `focus-visible:ring-offset-stone-900` pinned the offset to a dark colour in both modes; removing it lets the global `--ring-offset-surface` apply.                                                                                                                                                                                                                                                                                                                                                                                                                               | Correctness.                                                                                 | `components/ui/button.tsx`                                                                                                                                            |
| R-10 | **Dialog and Select popover colours are tokens.** `AccessibleDialog` and `SelectContent` hardcoded `rgba(28, 25, 23, 0.85/0.9)` inline, pinning both to the dark theme regardless of mode. Now `--glass-heavy-bg`, `--border-subtle` and `--elevation-overlay`.                                                                                                                                                                                                                                                                                                                                                                  | Prism rule, and a real light-mode bug.                                                       | those two files                                                                                                                                                       |
| R-11 | **`EmptyState` drop shadow is a token.** `rgba(232,143,71,0.15)` became `rgb(var(--brand-500)/0.15)`, so it follows the active palette.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Prism rule.                                                                                  | `components/ui/empty-state.tsx`                                                                                                                                       |
| R-13 | **The whole named-layer vocabulary was absorbed, not replaced.** Sixteen named `z-*` classes were already in use across roughly 180 call sites (`z-dialog`, `z-float`, `z-fab`, `z-page-bar`, `z-mobile-header`, `z-chrome`, `z-toast`, `z-command`, `z-offline`, `z-island`, `z-context-menu`, `z-system-overlay`, `z-subnav`, `z-status`, `z-fab-secondary`, `z-spotlight`) and none of them existed. Every name keeps its name and is given a value, rather than forcing a rename across 180 sites.                                                                                                                           | Recovering an existing decision beats imposing a new one.                                    | `tokens.json` `layer.scale`                                                                                                                                           |
| R-14 | **Dark-mode `--text-placeholder` raised to 4.96:1.** It was `stone-500`, measuring 4.12:1 against `surface-0`, failing WCAG AA for normal text. Found by rendering the catalog and running axe against it, not by reading the code.                                                                                                                                                                                                                                                                                                                                                                                              | Accessibility floor.                                                                         | `tokens.json` `semantic.text.text-placeholder.dark`                                                                                                                   |
| R-15 | **Field error text is theme-aware.** `text-red-600` measures 4.72:1 on light and 4.09:1 on dark. `Input`, `Textarea` and `Select` now use `text-red-600 dark:text-red-400` for the error message, the required asterisk and the character counter.                                                                                                                                                                                                                                                                                                                                                                               | Accessibility floor.                                                                         | those three files                                                                                                                                                     |
| R-16 | **`Switch` can receive an accessible name.** `aria-label` and `aria-labelledby` were spread onto the visually-hidden input, so they never reached the `role="switch"` button. The input is now `aria-hidden` and out of the tab order.                                                                                                                                                                                                                                                                                                                                                                                           | A switch with no name is unusable with a screen reader.                                      | `components/ui/switch.tsx`                                                                                                                                            |
| R-17 | **Five nested interactive elements removed.** `<a>` wrapping `<Button>` in five feature files was failing the repository's own `audit:a11y:markup:strict`, which is wired into CI, so that gate was red before this work started. All five became `<Button href>`. One of them also used an emoji as its icon; that became the Phosphor `Mail` icon with an `aria-label`.                                                                                                                                                                                                                                                        | The gate existed and was failing. Fixing it was cheaper than working around it.              | those five files                                                                                                                                                      |
| R-18 | **`logo-fallback` and `success-check` moved off raw hex.** `#44403c` became `rgb(var(--stone-700))`; `#10b981` became `var(--status-success-solid)`. `components/ui` is now hex-free apart from two registered exceptions.                                                                                                                                                                                                                                                                                                                                                                                                       | Prism rule, enforced by a unit test.                                                         | those two files                                                                                                                                                       |
| R-12 | **Brand stop 300 is a true interpolation.** The copper ramp had two duplicate stops (300 == 400, 600 == 700) as an artifact of expanding six identity swatches into eleven; the other seven palettes are monotonic. Stop 300 is now `245 209 171`. **Stop 600 was deliberately left pinned** to the deep swatch: `--focus-ring-color` resolves to it in light mode and measures 4.63:1, while an interpolated 600 drops to 3.49:1. Contrast beats ramp aesthetics.                                                                                                                                                               | Consistency, bounded by measured contrast.                                                   | `tokens.json` `brand.scale`                                                                                                                                           |

## Newly decided (genuine gaps)

| #    | Decision                                                                                                                                                                                                                                                                                                                                               | Reasoning                                                                                                                                                                                |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| N-01 | **The Prism rule** stated explicitly: no new hex, rgb, hsl or arbitrary colour for a role that already exists.                                                                                                                                                                                                                                         | The rule was implied by several documents but never stated as law. The runtime palette swap makes it a correctness requirement, not a style preference.                                  |
| N-02 | **Status roles as first-class tokens** (`--status-{success,warning,danger,info,neutral}-{bg,fg,border,solid}` plus `.status-*` classes), built from the values already in `contrast-contract.ts`. Meaning is global, silhouette is local.                                                                                                              | 12,957 red / amber / emerald utility usages were functioning as an undeclared status system. This declares it, and gives those usages a migration target. Every pair measures above 7:1. |
| N-03 | **A radius scale with semantic aliases**, explicitly not overriding Tailwind's numeric values.                                                                                                                                                                                                                                                         | `docs/research/...` calls the missing radius scale a genuine gap. Nine near-identical arbitrary radii sat in the 1.25 to 2rem band.                                                      |
| N-04 | **A three-tier elevation scale**, named rather than left as raw variables.                                                                                                                                                                                                                                                                             | Depth is carried by the surface scale; shadow is secondary. Three tiers is enough.                                                                                                       |
| N-05 | **`BREAKPOINTS`, `MEDIA`, `LAYER`, `DURATION`, `EASING`, `LIMITS` exported from `design-system/tokens/tokens.ts`.**                                                                                                                                                                                                                                    | Six files branched layout on a literal `window.innerWidth` number. There was no shared constant to import.                                                                               |
| N-06 | **Two visible families plus a functional monospace**, with `font-mono` given an explicit stack (it previously fell through to Tailwind's default) and the culinary board's six handwriting families registered as a scoped exception rather than deleted.                                                                                              | The board's handwriting is the interface metaphor, not decoration. Killing it would be throwing away working product for a rule. Confining it is the right answer.                       |
| N-07 | **`.media-scrim` as the only approved treatment for text over photography.**                                                                                                                                                                                                                                                                           | The brief says do not bury important media under aggressive gradients, and the repo had ad-hoc scrims.                                                                                   |
| N-08 | **The ratchet enforcement model.** `scripts/audit-design-system.mjs` records a per-rule baseline and fails only when a count increases.                                                                                                                                                                                                                | 3,033 raw hex hits exist. A zero-tolerance gate would fail on day one and be switched off, which protects nothing. A ratchet cannot be gamed and cannot be ignored.                      |
| N-09 | **Feature selection conditions.** Every entry in `features.json` carries `selectWhen`.                                                                                                                                                                                                                                                                 | The brief is explicit that not every feature belongs in every project. Without a condition, a registry becomes a shopping list.                                                          |
| N-10 | **Nav maximum fixed at 6.** The philosophy spec says 7, the `qol` skill says 5, and `docs/chef-navigation-decision-contract.md` fixes exactly six primary domains. The binding contract wins.                                                                                                                                                          | A real conflict, resolved by precedence rather than averaging.                                                                                                                           |
| N-11 | **Glassmorphism and gradients are kept.** `docs/research/interface-philosophy-enforceable-rules.md` section 9.1 (Rams) bans "trend-driven styling (gradients, glassmorphism)". The shipped product uses both extensively and deliberately, they are part of the warm identity, and they are tier-3 and tier-4 evidence against a tier-5 research note. | Recorded rather than silently ignored. See OPEN-CONFLICTS.md C-02.                                                                                                                       |
| N-13 | **Two new audit rules: `no-link-wraps-button` (427 hits) and `no-emoji-as-icon` (139 hits).** Neither was visible before. The existing `audit-a11y-markup.mjs` only catches a literal `<a>` wrapping a `<Button>`; a `next/link` `<Link>` renders an `<a>` too, so 427 nested interactive pairs went uncounted.                                        | Making debt visible and ratcheted is the point of the enforcement layer. Both start at their current count, so nothing breaks today and nothing can grow.                                |
| N-14 | **The audit engine gained file-level rules** alongside line-level ones, because the nested Link pattern spans two lines.                                                                                                                                                                                                                               | A line-based scanner cannot see a two-line pattern, and pretending otherwise would have reported zero.                                                                                   |
| N-12 | **The 2px half-step is legal** for dense control padding and icon gaps. 7,110 usages, 11% of all spacing.                                                                                                                                                                                                                                              | Declaring 11% of the codebase illegal would be the system losing an argument with reality. The 4px grid holds; the half-step is a named, bounded exception.                              |

## Rejected
