# Chromatic Atlas Source Registry

**Status:** Research crawl registry - 2026-05-20  
**Scope:** Research governance only. This file does not authorize an app build.

## Evidence Classes

| Class                  | Use                                                                            |
| ---------------------- | ------------------------------------------------------------------------------ |
| `measured`             | Instrument-measured value with method, unit, sample state, date, and citation. |
| `peer-reviewed`        | Scientific literature with DOI, PMID, or stable publisher URL.                 |
| `database-derived`     | Maintained academic, government, or scientific database.                       |
| `inferred`             | Derived from source-backed facts with derivation shown.                        |
| `culinary-precedent`   | Published culinary practice or food-culture source; not science proof.         |
| `chef-heuristic`       | Practitioner judgment; useful only when labeled.                               |
| `personal-thesis`      | Individual note or hypothesis; never universal.                                |
| `speculative`          | Plausible but not supported enough for product claims.                         |
| `rejected-unsupported` | Examined and banned as a claim source.                                         |

## Rejected Or Restricted Source Classes

| Source class                                       | Status                                        | Reason                                                   |
| -------------------------------------------------- | --------------------------------------------- | -------------------------------------------------------- |
| AI summaries, LLM outputs, generated embeddings    | `rejected-unsupported`                        | AI output is never evidence.                             |
| Web product photos                                 | `rejected-unsupported` for measured color     | Lighting/camera/compression/segmentation unknown.        |
| Recipe blogs and unsourced culinary pages          | `culinary-precedent` at best                  | Useful for language/hypotheses only.                     |
| Compound overlap charts without threshold evidence | `rejected-unsupported` for flavor claims      | Compound presence does not imply perception.             |
| Same-color pairing examples                        | `chef-heuristic` or `culinary-precedent` only | Same color never means same flavor or safe substitution. |

## License Rules

- If license cannot be determined, mark `restricted/unknown`.
- Store citation metadata separately from article text, figures, and tables.
- Do not cache or display full text, abstracts, figures, food tables, or repository files without license review.
- Public display is safe for identifiers, links, titles, source names, authors, years, and short claim summaries written by ChefFlow, not copied source text.
- Every source record needs access date, identifier, license status, and what the source does not support.
