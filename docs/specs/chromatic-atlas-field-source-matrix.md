# Chromatic Atlas Field-To-Source Matrix

**Status:** Research crawl draft - 2026-05-20  
**Purpose:** Define what each Atlas field may claim, what evidence is required, and what must remain "Not enough evidence."

## Field-To-Source Matrix

## Cross-Field Rules

- Color can index discovery only when paired with role, state, source, and confidence.
- Compound presence does not imply perceptible flavor unless concentration and threshold/perception evidence support it.
- Missing records mean **Not enough evidence**, not zero, not absence, and not "same as raw."
- Same botanical species does not prove cultivar-level flavor, texture, or color.
- Same color never means same flavor.

## Field Coverage Summary

| Coverage                   | Fields                                                                                                                                           |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| High readiness             | common name, scientific identity, food state where FDC has record, nutrients, source freshness, citation display                                 |
| Conditional readiness      | color family, measured image color, pigment family/behavior, aroma compounds, tastants, bitter compounds, pH/acidity, texture, culinary role     |
| Blocked for product claims | same-color substitution, pigment-to-flavor inference, compound-to-perception inference, cultivar-specific sensory claims without cultivar source |
