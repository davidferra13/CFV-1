# Chromatic Atlas Green Pilot Research

**Status:** Research crawl draft - 2026-05-20  
**Scope:** Source-backed feasibility map for the green pilot. This is not a finished ingredient database.

## Green Pilot Rules

- Every ingredient below is a candidate record, not a final product record.
- Botanical identities are candidate identities requiring authority resolution through GRIN, GBIF, POWO/WCVP, or WFO before product display.
- Culinary roles are `chef-heuristic` or `culinary-precedent` unless a source is named in a later ingredient record.
- Nutrient coverage estimates come from USDA FoodData Central availability notes; pH/acidity often remains **Not enough evidence**.
- Aroma/tastant/phenolic fields require database or literature lookup per ingredient; do not infer them from color.
- Color family is a discovery bucket only. Same green color never means same flavor.

## Cluster Readiness

| Cluster                                | Readiness              | Reason                                                                                             |
| -------------------------------------- | ---------------------- | -------------------------------------------------------------------------------------------------- |
| Green Acid / Fruit                     | Conditional            | FDC coverage mostly strong, but cultivar/type and pH/organic acids are uneven. Sorrel is weak.     |
| Green Water / Crunch / Body            | Better first proof set | FDC coverage strong and roles are distinguishable, but measured texture is mostly heuristic.       |
| Green Heat / Pyrazine / Aromatic       | Conditional            | Identity and FDC exist, but volatile/perception claims require careful database/literature lookup. |
| Green Fat / Bitter / Leafy / Preserved | Conditional            | Good contrast, but curing/cultivar/fermentation and bitter-compound claims are complex.            |

## Smaller Recommended First Proof Set

If the 24-ingredient pilot is too broad, start with eight records:

| Ingredient        | Why                                                    |
| ----------------- | ------------------------------------------------------ |
| Green apple       | Proves cultivar and acid-fruit handling.               |
| Lime              | Proves citrus identity/state split.                    |
| Cucumber          | Proves water/crunch role.                              |
| Celery            | Proves aromatic crunch role.                           |
| Green bell pepper | Proves pyrazine/aromatic role without heat.            |
| Jalapeno          | Proves same species can diverge by cultivar/role/heat. |
| Avocado           | Proves fat/cream role inside green color.              |
| Green olive       | Proves preserved/briny role and state transformation.  |

This set demonstrates that "green" spans acid, water, aromatic, heat, fat, and preserved roles without forcing unsupported completeness.
