---

## What This Means

A client using ChefFlow fully only leaves for:

1. **Discovery ecosystems they already trust**: Google, Instagram, TikTok, Yelp, friends.
2. **Native communication channels**: SMS, WhatsApp, phone, external email.
3. **Financial rails**: banks, card apps, Venmo/Zelle, chargebacks, reimbursement tools.
4. **Non-food event vendors**: venues, rentals, florists, entertainment, invitations, travel.
5. **Social memory**: photos, public reviews, referrals, personal albums.
6. **Legal/medical/procurement review**: lawyers, employer approvals, health sources, regulated checks.

Everything else: discovery inside ChefFlow, booking, quotes, contracts, payment status, event details,
menu approval, dietary collection, guest links, household memory, documents, rewards, referrals,
recaps, feedback, and repeat booking can happen without leaving.
