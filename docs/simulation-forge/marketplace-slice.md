# Simulation Forge: bounded ChefFlow marketplace twin

Status: offline synthetic model, no live marketplace behavior. Branch `feat/simulation-forge-marketplace-20260928` starts from the pushed booking/Forge checkpoint `ba2a12418`.

The simulation reuses the generic `runScenario` interface and calls unchanged ChefFlow `lib/intelligence/chef-capacity-twin.ts#buildCapacityProfile` and `#deriveCapacityDecision` at quote and confirmation time. ChefFlow's public `lib/booking/match-chefs.ts` is server-only and fetches directory/location state; it is not invoked offline. The capacity decision checks modeled workload and weekly limits, while price, geography, one booking per chef/date, seasonality and cancellations are explicit Forge assumptions.

The first client inherits the historical Enthusiast persona. Three other clients, three chefs, two to four requests, chef prices, geography and availability are synthetic. In winter the bounded seeded draw produces two or three requests; in summer three or four. The six distinct trial seeds are sampled to expose model sensitivity, not estimate customer demand or forecast revenue. The twin performs no money movement, account access, network request, customer message or database write.

`node --import tsx --test tools/simulation-forge/marketplace.test.mjs tools/simulation-forge/core.test.mjs` checks production capacity-rule invocation, matching constraints, cancellation release, price and budget boundaries, seasonality, paired seeds, and run identity. `node --import tsx tools/simulation-forge/cli.mjs release` includes the normal market, seven mutations, and the retained minimized market case in the same bounded suite as the discovery and booking slices. A blocked or unmatched demand request is an unmet synthetic need, never a successful booking.

`node --import tsx tools/simulation-forge/cli.mjs marketplace-proof` writes `docs/simulation-forge/marketplace-evidence.json` and `tools/simulation-forge/fixtures/marketplace-availability-regression.json`. The injected fault skips the chef availability recheck after a synthetic quote; the invariant catches an unsafe allocation. The normal adapter blocks it. Raw trajectories, observations, scores, source commit, minimized sequence, fixed replay, six paired before/after seeds and demand sensitivity are preserved separately. Results are hypotheses about this small model and cannot establish real market supply, conversion, pricing elasticity or revenue.

The generic core now includes source commit, evaluator version, configuration ID and budget in run IDs. Repeat the same seed and commit for deterministic reproduction; change seed to inspect bounded stochastic variation. Older proof files retain their original run IDs and source commit. The native ChefFlow release firewall remains blocked by seven missing `/studio*` routes tracked `CF-STUDIO-NAV-20260928`; do not infer production release from an offline Forge suite.
