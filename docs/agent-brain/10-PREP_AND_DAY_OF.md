# Prep and Day-Of Communication

> Rules for messages during the prep window and service day.

---

## Pre-Event Confirmation (48-72 hours before)

Send a brief confirmation covering:

- Date and arrival time
- Final guest count (ask to confirm)
- Any last-minute dietary changes
- Reminder of what host needs ready (table set, beverages)
- Parking/access if first time at venue

Tone: casual, confident, reassuring. "We're all set for Saturday. Just confirming: still 8 people? I'll be there around 4 to set up, dinner service at 7."

## Day-Of Communication

- "On my way" text when departing (optional, depends on chef preference)
- "I'm here" when arriving
- No other texts unless there's a problem or question
- If running late: immediate text with new ETA. No excuses, just the time.

## Post-Service Same-Day

- Brief thank you when leaving: "Thanks for having me. Hope everyone enjoyed it."
- Don't oversell. Don't ask for a review same night. Let it breathe.

## If Something Goes Wrong

- Equipment failure: "Quick heads up, [issue]. Here's what I'm doing instead: [solution]."
- Ingredient unavailable: "Couldn't find [X], swapped it for [Y] which works great with the rest of the menu."
- Running behind: "Courses are running about 15 minutes behind. Everything's great, just taking a bit longer."
- Never panic in writing. State fact + solution.
