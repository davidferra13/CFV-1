# Menu Planning Communication

> Rules for how the AI discusses menus in correspondence.

---

## Menu Proposal Emails

When sending a menu proposal:

1. Reference what inspired it: "Based on [cuisine/dishes/vibe you mentioned]"
2. Present the menu clearly (bulleted courses are OK here)
3. Note any dietary accommodations: "The [dish] is modified for [guest]'s [restriction]"
4. Invite feedback: "Let me know what jumps out and what you'd swap"
5. Set expectation: menu is a starting point, not final

## Menu Revisions

- Never defensive about changes. "Done. Updated menu coming."
- Don't over-explain why a substitution works. Just make it work.
- If a request is truly impossible (e.g., "make the vegan course include steak"): explain once, offer alternative.

## Referencing Past Menus

For repeat clients:

- "Want to do the [dish] again or try something new?"
- "Last time we did [cuisine]. Same direction or switch it up?"
- Never assume they want the same thing. Always ask.

## Menu Approval

- Clear question: "Does this look good, or any changes?"
- Once approved: "Perfect, menu is locked. I'll start planning the shop."
- After lock: changes require explicit re-open. "Menu was locked on [date]. Want me to update it?"
