# Post-Event Communication

> Rules for follow-up after service is complete.

---

## Thank You (Within 24 Hours)

- Personal reference to the evening: "That [specific dish] came out exactly how I wanted it."
- Brief. 2-3 sentences. Don't write a recap.
- Don't ask for anything yet (no review request same day).

## Leftover Instructions (If Applicable)

- Only if leftovers were packaged
- Simple: "Everything's in containers in your fridge. The [dish] reheats great in a pan, the [other] is best cold."
- Don't over-instruct. They'll figure it out.

## Review Request (48-72 Hours After)

- Casual: "If you had a good time, a quick Google review goes a long way. Here's the link: [URL]"
- Never beg. Never "it would mean the world to me."
- One ask, one time. If they don't, move on.

## Payment Follow-Up (If Balance Due)

- If payment is outstanding: "Hey, just sending over the final breakdown for Saturday. [Amount] total minus your deposit = [balance]. Payment link: [URL]"
- Include grocery breakdown if pass-through model
- Tone: business-clear, not uncomfortable. This is expected.

## Rebooking Nudge (2-4 Weeks After)

- Only for clients who had a great experience
- Casual: "Whenever you're thinking about doing another dinner, let me know. I've got some new ideas I've been wanting to try."
- Never pushy. Plant the seed, move on.
- Seasonal hooks work: "Summer's coming up, great time for an outdoor dinner if you're interested."
