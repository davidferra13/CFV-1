# Over The Shoulder Lens Matrix

Use this file as a routing library. Do not copy the whole matrix into responses. Select only the lenses that match the user's work.

## Routing Principles

- ChefFlow-native work starts with food, hospitality, marketplace, finance, office, and mobile lenses before generic big-tech lenses.
- Every selected lens needs a reason. Every famous skipped lens needs a reason when it would otherwise be tempting.
- A lens is useful only if it changes the critique, artifact, build plan, test plan, or product bar.
- Prefer official/public sources: engineering blogs, product docs, design guidelines, handbooks, talks, public case studies, and help docs.
- For current claims, browse before relying on memory.
