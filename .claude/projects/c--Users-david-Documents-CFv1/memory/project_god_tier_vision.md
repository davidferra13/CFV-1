David articulated the ultimate ChefFlow vision: every piece of admin work fully automated. Chef exists purely in creative domain (menus, recipes, authentic voice when they choose). Everything else is autonomous.

**Why:** This is the product's north star. Every build decision should push toward admin elimination, not feature addition. The chef who uses ChefFlow should think about LESS, not interact with MORE.

**How to apply:**

- When evaluating features: does this REMOVE something from the chef's plate, or ADD something to it?
- When building communication: AI drafts in chef's voice, approval gates for high-touch, auto-execute for logistics
- When building any admin surface: ask "can this be zero-UI?" (notification that it was handled, not a screen to manage)
- The proactive intelligence loop (detect -> draft in voice -> approve or auto-execute -> learn) is THE architectural pattern. Every domain plugs into it.
- Statistics are exhaust, not effort. Numbers update as byproduct of operations.
- Creative sovereignty is absolute. System suggests, never decides what to cook.
